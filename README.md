# E-Commerce Sales & Customer Intelligence Analysis

# Project Overview
This project analyzes Brazilian e-commerce marketplace data to identify revenue trends, customer behavior, seller performance, and delivery efficiency using Python, PostgreSQL, SQL, and Power BI.

# Business Objective
The objective of this project is to perform end-to-end e-commerce analytics and generate actionable business insights related to:
- Sales performance
- Customer retention
- Seller performance
- Delivery efficiency
- Customer satisfaction

# Tools & Technologies
- Python
- Pandas
- PostgreSQL
- SQL
- Power BI
- Jupyter Notebook

# Project Workflow
- Raw Data → Data Cleaning (Python) → PostgreSQL Analysis → Power BI Dashboard → Business Insights

# Key Analysis
- Revenue Trend Analysis
- Customer Segmentation
- Repeat Customer Analysis
- Seller Ranking Analysis
- Delivery Delay Analysis
- Customer Satisfaction Analysis
- Payment Method Analysis
- Regional Revenue Analysis

# Insights 
- Customer review scores decreased significantly in orders with higher delivery delays, indicating that logistics performance had a direct impact on customer satisfaction and overall customer experience.
- A small number of states contributed the majority of platform revenue, with regions like SP and RJ emerging as the strongest revenue-generating markets.
- Revenue contribution was heavily concentrated among top-performing sellers, while a large number of sellers contributed comparatively lower sales volume.
- Customers with repeat purchases contributed significantly to overall platform activity, indicating strong opportunities for loyalty and retention-focused strategies.
- Customer segmentation analysis revealed distinct high-value, medium-value, and low-value customer groups based on spending behavior.
